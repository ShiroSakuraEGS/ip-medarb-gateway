# 03 UX FLOW｜使用者操作流程

- Project ID：CI-2026-001　　版本：v0.1

## 1. 簡報瀏覽旅程
進入 `index.html`（封面）→ 以鍵盤、螢幕按鈕或觸控滑動逐頁閱讀 → 第 9–10 頁可進入「通道示範」→ 第 14 頁後可開來源附錄 → 可列印 PDF。

## 2. 頁面清單
| 頁面 | 路徑 | 目的 |
|---|---|---|
| 簡報 1–14 | `/index.html#1` … `#14` | 論述與數據 |
| 來源附錄 | `/index.html#sources` | 出處與核對狀態 |
| 通道示範 | `/gateway.html` | 互動模擬 |

## 3. 通道示範流程
```
選擇模式 A／B／C
        ↓
填寫／確認示範申請（案件類型、語言等；資料已預填且標「示範」）
        ↓
雙方確認 ──不同意／僅單方同意──→ 繼續原程序（結束頁，說明不可單方強制轉換）
        ↓ 雙方同意
專家配對（示範名單，可選一位）
        ↓
程序銜接（依模式顯示暫停仲裁／先調解／恢復條件）
        ↓
調解結果 ──成功──→ 示範和解協議確認
           ──未成功──→ 依約恢復仲裁說明
```

## 4. 文案與語氣
- 語言：繁體中文，香港用詞。
- 語氣：嚴謹、克制、不誇大；互補而非取代。
- 禁用：把推算寫成「預計將達到」「官方預測」；把 24 宗寫成現況；熱連結未授權圖片。

## 5. 無障礙與 RWD
- 焦點可見；按鈕有文字；圖表旁有數據表。
- 手機：簡報改為直向可捲動；導航固定於底部。
