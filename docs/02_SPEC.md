## 1. 範圍
- 本版包含：靜態 14 頁網頁簡報、資料來源附錄、一鍵通道互動模擬、本機測試、GitHub Actions Pages 工作流程範本（尚未推送）。
- 本版不包含：真實後端、登入、付款、真實專家名冊、自動寄信給當事人、公開部署。

## 2. 功能規格

### F-01 十四頁網頁簡報
- 描述：單頁或多頁靜態 HTML，依大綱 Part 1–4 呈現 14 頁。建議頁序：
  1. 封面：智財仲調結合——一鍵轉換數位通道；副標題與標語 From Dispute to Dialogue, From Competition to Collaboration.
  2. 背景：AI 與知識經濟；四個爭議場景；WIPO 2025 關鍵數據（含來源與範圍說明）
  3. 為何是香港：制度與人才優勢；HKIAC 2025：388 宗、84.3% 國際、61 個司法管轄區
  4. 2020–2026 市場：已公布仲裁宗數與國際比例圖；註明 2026 未公布；補上 IP 類型佔比（已公布）及「沒有完整國際 IP 獨立案件數序列」
  5. 2026–2030 推算：6% 路徑與 3%／5.4%／8% 敏感度；必須標「推算情境（非官方）」；並列已公布 IP 佔比作為對照
  6. 調解 vs 仲裁對照表；核心訊息：互補而非競爭
  7. 三大需求：人力、技術、機制（含三種銜接）
  8. 四個待驗證痛點（資訊分散、轉介成本、專業配對、跨境協作）；不宣稱現有制度失效
  9. 方案：定位、四大功能、非取代機構
  10. 一鍵轉換流程圖與法律保障（雙方同意、暫停與時限、資料隔離、和解效力）；「一鍵≠自動轉化法律程序」
  11. 四個技術模組；AI 僅輔助
  12. 六大好處
  13. 戰略定位：從爭議解決中心到國際創科中介者
  14. 結語；可含三種服務模式 A／B／C 摘要與試行 KPI（標示為建議目標，非現況）
- 驗收：Given 開啟 index.html，When 逐頁瀏覽 1–14，Then 每頁標題與核心論點完整且無佔位文案。

### F-02 導航與 RWD
- 鍵盤：ArrowLeft／ArrowRight／Space／Home／End；觸控滑動；頁碼指示。
- 斷點：360／768／1280。投影片在桌面以 16:9 或接近投影比例呈現；手機改為可捲動卡片，不依賴橫向溢出。
- 驗收：Given 360px 與 1280px，When 走完所有頁，Then 主要文字可讀、導航可用、無 Console 錯誤。

### F-03 圖表與數據規則
- 圖表一：HKIAC 2020–2025 全部仲裁宗數（柱）＋國際比例或國際約數。2026 標示「尚未公布」。
- 圖表二：2026–2030 國際仲裁推算（線或柱），全圖標籤「推算情境（非官方）」。
- 圖表三（建議）：已公布 IP 類型佔比（缺 2024 單獨數字則標「未單獨公布」）。
- 2030 年 13／24／35 宗必須附假設比例，並註明高於近期已公布佔比。
- 驗收：Given 對照 FACTCHECK.md，When 檢查圖表與註腳，Then 數字一致，沒有把推算畫成與已公布數據同一圖例系列而不加區分。

### F-04／F-05 流程圖與來源
- 第 10 頁以 SVG 或 HTML 流程呈現：爭議發生 → 進入通道 → 雙方是否同意轉調解 → 同意則配對與協商／不同意則繼續原程序 → 調解成功簽和解／未成功依約恢復仲裁。
- 來源頁列出 URL、取用日期、核對狀態（✔／⚠）。
- 驗收：每項已引用數據可在來源頁找到對應出處。

### F-06 列印 PDF
- `@media print`：每頁投影片分頁；隱藏導航鈕；背景與文字對比足以閱讀。
- 驗收：列印預覽可見 14 頁（及來源附錄），不被裁切至無法閱讀。

### F-07 通道模擬
- 步驟：一鍵申請 → 雙方確認 → 專家配對 → 程序銜接。
- 使用者可選模式 A（仲裁前調解）、B（仲裁中轉調解）、C（調解失敗回歸仲裁）。
- 雙方確認：必須兩方都同意才能進入調解；單方申請不得強制轉換。
- 結果：成功 → 示範和解協議確認頁；失敗 → 恢復仲裁說明頁。
- 所有姓名、案件編號、專家名單均為虛構，並標「示範資料」。
- 驗收：Given 選擇任一模式，When 完成同意路徑與拒絕路徑，Then 畫面與文案符合上述規則，且不送出任何網路請求（除開啟本機檔案）。

### F-08 離線與安全
- Chart.js 等函式庫放在 `vendor/`；不使用 CDN、不熱連結外站圖片。
- 不收集個人資料；無分析追蹤碼。

## 3. 非功能需求
| 項目 | 要求 |
|---|---|
| 效能 | 本機或 Pages 開啟後首屏可交互 < 3 秒（一般網路／本機） |
| 響應式 | 360／768／1280 可正常使用 |
| 瀏覽器 | Chrome／Safari／Edge 近兩版；以 Chromium 自動測試為準 |
| 語言 | 繁體中文（香港用詞：仲裁、調解、司法管轄區） |
| 安全與隱私 | 無金鑰、無真實當事人資料；模擬資料標示範 |
| 無障礙 | 鍵盤可操作；圖表有文字對照；對比度可讀 |

## 4. 資料與內容

- 法律文案保持審慎：痛點是「待驗證問題」；KPI 是「建議試行目標」。
