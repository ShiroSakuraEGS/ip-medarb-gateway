## 必須在簡報中分開標示的三類數據
1. **已公布數據**：HKIAC 全部仲裁宗數、國際比例、61 個司法管轄區、爭議類型中的 IP 佔比、WIPO ADR Highlights 2025。
2. **IP 專項限制**：沒有完整的「國際 IP 仲裁獨立案件數」年度序列；2024 年 IP 佔比無法單獨核實；類型佔比 ≠ 國際 IP 案件數。
3. **推算情境（非官方）**：6% 增長路徑、3%／5.4%／8% IP 敏感度。不得讓閱聽者誤以為香港每年實際有 24 宗國際 IP 仲裁。
